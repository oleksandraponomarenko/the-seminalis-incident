# Supporting assets

[Project overview](../README.md) · [Experiment log](../experiment-log.md)

This directory is reserved for anonymized photographs or supporting material added later. The initial repository documentation includes no photographs or conversation transcripts.

## Adding material

- Add only material the investigator has selected for this repository.
- Review photographs and documents for names, addresses, receipts, shipping labels, reflections, location clues, account details, and embedded metadata before publication. Remove identifying details from the publication copy and preserve any original separately.
- Use descriptive filenames, such as `jacket-and-cleaner.jpg`, without embedding a date unless that date is documented.
- Give each asset a brief caption stating what is visible, who supplied it, and its relation to an experiment-log entry. Mark unavailable capture dates as “not recorded.”
- A product label may support transcription of legible label text. It does not independently verify ingredients, biological activity, or effectiveness.
- A photograph of the jacket or cleaner can document visible context. It cannot establish odor intensity, application quantity, exposure time, or treatment outcome.
- Do not create simulated before/after photographs or reconstruct missing evidence. If an image is cropped or redacted, disclose the modification in its caption.
- Link any added file from the relevant record and verify the relative path.

Filename:

Visible content:
